# 計算スピードチャレンジ (Math Speed Challenge)

2桁×2桁の掛け算と4桁の素因数分解を制限時間内に解く、暗算・計算トレーニングWebアプリケーションです。

## 主な機能

- **⚡ 掛け算アタック (2桁×2桁)**:
  - 10〜99 の掛け算問題を全10問出題
  - 制限時間: 1問15秒
  - タイムアップ時は正解を表示し、3秒後に次の問題へ自動遷移
- **🧩 素因数分解チャレンジ (4桁)**:
  - 1000〜9999 の合成数を全5問出題
  - 制限時間: 1問30秒
  - 指数表記（例: `2^3 * 3^2 * 5`）や積形式（例: `2*2*2*3*3*5`）、スペース区切りのいずれにも対応
  - タイムアップ時は正解（例: `2³ × 3² × 5`）を表示し、3秒後に次の問題へ自動遷移
- **操作性**:
  - PCキーボード（テンキー、Enterキー送信）
  - スマホ・タブレットでも快適なオンスクリーン・キーパッド（素数ショートカットチップ付き）
- **結果・振り返り**:
  - 正解数、正答率、平均解答時間
  - 全問題の履歴一覧テーブル

## 技術スタック

- HTML5
- CSS3 (Vanilla CSS, グラスモーフィズム, レスポンシブ対応)
- JavaScript (Vanilla JS, Web Audio API サウンド)

## 起動方法

依存ライブラリのインストールは不要です。ブラウザで直接開くか、ローカルサーバーで実行してください。

```bash
# Pythonの簡易サーバーで起動する場合
python -m http.server 8085
```

ブラウザで `http://localhost:8085` にアクセスしてください。
